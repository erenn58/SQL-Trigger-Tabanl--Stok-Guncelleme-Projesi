📦 SQL Trigger Destekli Stok Yönetimi – Konsol Uygulaması

Bu proje, C# ile geliştirilmiş basit bir konsol uygulamasıdır.
Uygulama, SQL Server veritabanına bağlanarak ürün ekleme, listeleme ve sipariş oluşturma işlemlerini gerçekleştirir.
Sipariş oluşturulduğunda, SQL Server üzerinde tanımlı trigger otomatik olarak çalışarak ürün stoklarını günceller.

🎯 Projenin Amacı

Konsol uygulamasının SQL Server ile nasıl haberleştiğini göstermek

Trigger ile veritabanı işlemlerinin nasıl otomatikleştirileceğini uygulamalı olarak göstermek

Temel CRUD + Trigger mantığını basit bir uygulamayla birleştirmek

Öğrenme amaçlı küçük ama anlamlı bir proje oluşturmak

🛠 Kullanılan Teknolojiler

C# (.NET Console Application)

SQL Server

ADO.NET

Trigger (AFTER INSERT)
